PokerData provides a downloadable library of GTO poker solver simulations for NLHE and PLO. It offers preflop ranges, postflop strategy, and EV data via a JSON ranges API and an MCP server. Users can access free 6-max NL preflop ranges and purchase full simulation bundles.

**Areas:** poker · GTO · solver · NLHE · PLO
